# 🎮 Suite CARP — Launcher de Herramientas para Winning Eleven 2002

> *"Todo lo que necesitás para darle tu sello personal a Winning Eleven 2002… en un solo clic."*

Este proyecto es un **frontend unificado** que reúne todas mis herramientas de modding desarrolladas a lo largo de los años para personalizar *Winning Eleven 2002* (versión PC). Bajo el pseudónimo **CARP**, comencé a modificar este juego en los 2000, y hoy compilo ese conocimiento en una interfaz centralizada, fácil de usar y lista para la comunidad.

---

## 🧰 Herramientas incluidas

Desde este launcher podés acceder directamente a:

- **RA Maker**  
  → Crea bancos de audio `.RA` con comentarios y relatos personalizados (usando clips `.VAG`).

- **SinSala-BIN**  
  → Edita archivos `.BIN` que contienen gráficos y paletas del juego (menús, escudos, banderas, etc.).

- **WAV2VAG / VAG2WAV**  
  → Convierte entre formato de audio estándar (`.WAV`) y el formato comprimido del juego (`.VAG`).

- **Extractor de VAGs**  
  → Extrae clips de audio individuales desde archivos `.RA` o `.VAG` empaquetados.

- **Creador de Estadios**  
  → Permite diseñar y exportar estadios personalizados compatibles con el motor del juego.

- **La Pinta**  
  → Editor de píxeles para imágenes del juego, con soporte para **16 colores** y **256 colores** (modo indexado), ideal para sprites, menús y fondos.

- **+ Otras utilidades**  
  → Pequeñas herramientas adicionales para conversión, validación y prueba rápida de assets.
